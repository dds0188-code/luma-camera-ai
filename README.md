# Luma Camera AI

한국어 기본 UI를 제공하는 오프라인 우선 개인용 AI 카메라 앱입니다.

## 목표 플랫폼
- Android: APK
- Windows: 데스크톱 앱
- macOS: 데스크톱 앱

웹 앱은 개발 범위에 포함하지 않습니다.

## 핵심 목표
- 촬영 전 구도, 촬영 각도, 거리감, 줌/렌즈 선택 가이드
- 수평선, 삼분할, 대칭, 여백, 피사체 위치 기반 구도 분석
- 지원되는 카메라에서 ISO, 셔터 속도, 초점, 화이트밸런스, 줌 등 수동 제어
- 촬영 후 사진의 구도, 수평, 선명도, 노출 평가
- 노출, 대비, 하이라이트, 그림자, 화이트밸런스 등 후처리 값 추천
- 모든 이미지 분석과 AI 추론은 기기 내부에서 실행
- 외부 AI API 및 유료 토큰 사용 금지
- 사진은 기본적으로 기기 밖으로 전송하지 않음

## 기술 방향
공통 UI와 도메인 로직은 Kotlin Multiplatform 및 Compose Multiplatform을 우선 검토합니다. 카메라 제어는 플랫폼별 네이티브 API를 사용합니다.

- Android: CameraX
- Windows: Media Foundation
- macOS: AVFoundation
- 영상/기하 분석: OpenCV
- 온디바이스 모델: LiteRT 또는 ONNX Runtime (모델 라이선스와 기기 성능 검토 후 확정)

카메라와 기기가 지원하지 않는 수동 제어 항목은 비활성화하거나 숨깁니다. 단일 카메라 영상만으로 정확한 물리적 거리나 3D 촬영 각도를 확정할 수 없는 경우에는 추정/가이드로 표시합니다.

## 개발 단계
1. 멀티플랫폼 프로젝트 구조 및 빌드 자동화
2. Android, Windows, macOS 카메라 미리보기와 촬영/저장
3. 구도 그리드, 수평계, 기본 기하 분석
4. 온디바이스 피사체/장면 분석 및 구도 추천
5. 수동 카메라 제어, 노출 보조, 히스토그램
6. 촬영 후 사진 평가와 보정값 추천
7. APK, Windows 설치 패키지, macOS 앱 패키징 및 실기기 테스트

## 개인정보 및 비용 원칙
네트워크 기반 AI API 호출 없이 로컬 처리를 우선합니다. 모델 파일은 사용 조건과 배포 라이선스를 확인한 뒤 포함합니다. 구독이나 서버 토큰 비용을 전제로 하지 않습니다.

## 현재 상태
프로젝트 요구사항과 기술 방향을 정리한 초기 문서 단계입니다. 실제 카메라 연동, 모델 통합, 각 운영체제 빌드 및 실기기 검증은 아직 완료되지 않았습니다.
